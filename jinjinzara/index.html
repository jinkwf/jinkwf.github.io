발급받은 영구 API 토큰을 붙여넣으세요. 아직 없다면 발급 안내를 먼저 보세요.

-남은 Anlas

토큰은 이 브라우저 저장소에만 보관되고, 생성 요청을 보낼 때 NovelAI 서버(novelai.net)로만 전송돼요. 진진자라는 따로 서버가 없어서 토큰이나 그림을 받아 가지 않습니다.

STEP 3 · 사용 방법

제작실 사용 방법

등장인물 등록 → 대본 → 컷 생성 → 말풍선 정리 → 저장 순서로 작업해요.

1. 등장인물 등록

제작실 등장인물 탭에서 인물을 추가하고 이름과 외형 태그(영어 Danbooru 태그)를 적어요. 이 태그가 그 인물이 나오는 모든 컷에 들어가서 외형이 유지돼요.

  • NovelAI로 뽑은 PNG를 올리면 그림 속에 저장된 프롬프트를 읽어 외형 태그를 자동으로 채워요.
  • 대본에 나오는 인물은 모두 외형 태그가 있어야 생성돼요. 등록 안 된 이름이나 태그가 빈 인물이 있으면 원고 위에 빨간 안내가 뜨고 생성 버튼이 잠겨요. 안내의 등장인물에 추가를 누르면 빠진 이름이 바로 등록돼요. (???처럼 정체를 숨긴 화자는 검사하지 않아요.)
  • 의상 세트에 교복·사복처럼 옷 태그 묶음을 저장해 두고, 대본에서 이름[교복]으로 골라요. 기본 의상을 정해 두면 고르지 않은 컷은 그 옷을 입어요. 외형 태그에는 얼굴·머리처럼 바뀌지 않는 것만 두는 게 좋아요.
  • 캐릭터 레퍼런스를 켜면 올린 이미지를 NovelAI V4.5의 캐릭터 레퍼런스로 함께 보내 얼굴과 옷을 더 비슷하게 맞춰요. 대신 컷마다 Anlas가 추가로 들어요(Opus도 무료 대상 아님).

로그 밖의 정보 알려주기: 설정·장소 탭

플레이 로그에는 "지금 무슨 일이 일어나는지"만 있고 장소가 어떤 곳인지는 거의 안 나와요. 제작실 설정·장소 탭에 한 번 적어두면 각색할 때마다 자동으로 쓰여요.

  • 작품 설정: 세계관·분위기·인물 관계. 설정 문서를 통째로 붙여넣어도 돼요. 설정에서 장소 뽑기를 누르면 NovelAI가 설정 속 장소를 찾아 장소 사전에 넣어 줘요.
  • 장소 사전: 장소 이름·다른 이름·모습 설명·이미지 태그. 상태창이나 로그에 이 이름이 나오면 그 태그가 모든 컷 배경에 들어가고, 다른 장소 태그(bathroom 등)는 검수에서 빠져요. AI로 태그 만들기로 태그 초안을 받을 수 있어요.
  • 이번 장면 메모: 로그 변환 창에서 직전 상황·옷차림처럼 로그에 없는 걸 한두 줄 적어요. AI가 로그보다 우선해서 반영해요.
  • 이전 장면 이어받기: 변환한 대본을 넣으면 그 장면의 장소·시간·요약이 저장되고, 다음 로그를 변환할 때 함께 넘어가요. 다음 로그에 상태창이 없으면 장소와 시간도 이어받아요. 새 화를 만들어도 이어져요.
  • 로그 변환 창 위쪽에 어디서 장소를 찾았는지(상태창·본문·이전 장면)가 보여요. 사전에 없는 장소면 장소 사전에 등록을 눌러 바로 추가하고 태그를 받아요.

캐릭터 채팅 플레이 로그가 있다면

대본 탭의 플레이 로그 변환을 누르고 채팅 로그를 붙여넣으세요.

  • NovelAI로 각색 (추천): 연결한 토큰으로 NovelAI 텍스트 AI(GLM)가 로그를 웹툰 대본으로 각색해요. 핵심 사건·감정이 꺾이는 지점·결정적 대사는 살리고, 눈에 보이는 행동과 배경은 그림 태그로, 속마음만 나레이션으로 옮겨요. 컷마다 구도(와이드·카우보이샷·클로즈업)를 바꿔 리듬을 만들고, 장소·시간 태그를 컷마다 이어 붙여요. 구독 중이면 텍스트 생성은 Anlas가 들지 않아요. 긴 로그는 나눠서 처리해서 1~2분 걸릴 수 있어요.
  • 바로 변환: 사이트 안에서 규칙으로 즉시 나눠요. 이름만 있는 줄은 다음 대사의 화자로, "그/그녀"·성 뺀 이름(지한)·별칭도 인물로 알아봐요. 달빛·골목·비·눈물·어깨를 붙잡다 같은 한국어 묘사를 태그로 바꾸고, 보이는 행동만 있는 문장은 나레이션에서 빼고 그림에 넣어요.
  • 다른 AI용 요청문 복사: 같은 각색 규칙을 Claude·ChatGPT에 붙여넣을 수 있게 복사해요.
  • 상태창 읽기: 로그의 ``` 상태창에서 날짜·시간·장소·요약을 읽어 각색에 반영해요. 예를 들어 [ 2026년 4월 11일 l 오후 l 잿길 쉼터 ]면 모든 컷을 오후(afternoon)로 맞추고, 상태창 자체는 검은 화면 컷으로 그대로 살려요. {{…}} 행동 지시는 대사로 넣지 않고 장면 참고로만 써요.
  • 자동 검수: 각색 결과는 사이트가 한 번 더 점검해요. 그림에 나오는데 인물 줄이 없으면 채우고, 인원 태그(2boys 등)를 실제 인물에 맞추고, 겹친 구도 태그와 엉터리 태그를 정리하고, 상태창과 다른 시간 태그를 고쳐요. 무엇을 고쳤는지는 결과 위 "자동 보정"을 열면 보여요. 대본 탭의 대본 점검으로 직접 쓴 대본이나 다른 AI 결과도 같은 검수를 받을 수 있어요.
  • "큰따옴표"는 말풍선, ‘작은따옴표’·(괄호)는 생각, [대괄호 한 줄]과 ``` 백틱 세 개로 감싼 부분은 상태창(여러 줄 그대로)이 돼요. 외쳤다·속삭였다·떨리는 목소리 같은 서술이 붙은 대사는 외침·속삭임·떨림 풍선으로 바뀌어요.
  • 이름 연결에서 로그 속 이름이나 {{user}}를 등장인물로 바꿀 수 있어요. 자주 쓰는 호칭은 등장인물 카드의 별칭에 적어 두면 대본과 로그 모두에서 그 인물로 인식해요.

줄글 스토리만 있다면

스토리로 대본 만들기를 누르고 스토리를 붙여넣은 뒤 NovelAI로 대본 만들기를 누르면 같은 규칙으로 각색해요. 다른 AI를 쓰고 싶으면 요청문을 복사할 수도 있어요.

이미지 프롬프트 자동 보정

생성할 때 장면 태그에 인원 태그(1boy·2boys·1girl, 1boy 등)가 없으면 등장인물 외형 태그의 성별로 채우고, 인물이 있는데 no humans가 들어 있으면 빼요. 구도 태그가 없으면 인원에 맞춰 upper body나 cowboy shot을 붙여요. 등장인물 외형 태그에 1boy나 1girl을 꼭 넣어 두세요.

  • 순서: 컷 내용(인원 → 구도 → 장소·시간·분위기) → 공통 화풍 → 품질 태그 순으로 보내요. 앞쪽 태그가 더 세게 먹어서, 화풍이 컷 내용을 덮지 않게 했어요.
  • 두 인물 사이의 행동: hug·kiss·hand on another's cheek 같은 태그는 NovelAI 형식(source#hug / target#hug / mutual#holding hands)으로 바꿔서 누가 누구에게 하는지 알려 줘요. 이런 컷은 인물 위치를 고정하지 않고 AI가 붙여 그리게 해요.
  • V5·직접 입력 모델도 V4.5의 품질 태그와 제외 프리셋을 써요.
  • 컷 메뉴(⋯)의 NovelAI에 보낼 프롬프트 보기로 실제로 보내는 프롬프트를 확인할 수 있어요.
  • 그림체가 웹툰 같지 않으면 설정 탭의 화풍 프리셋을 골라 보세요. 캐릭터 레퍼런스를 쓰는데 표정·행동이 안 바뀌면 충실도를 0.6~0.75로 낮춰 보세요.

3. 컷 만들기와 생성

설정 탭의 컷당 후보 수(1~4장)만큼 그려서 그중 하나를 골라요. 그림 아래 버전 목록에서 눌러 바꾸고, 필요 없는 버전은 지울 수 있어요. 새 후보는 다른 시드로 더 그리고, 다시 그리기는 고른 그림과 같은 시드로 다시 그려서 태그만 고친 결과를 비교할 때 좋아요. 컷마다 최근 6장까지 보관해요.

전체 생성을 누르면 생성할 컷 수, 후보 수, 모델, 레퍼런스, 예상 Anlas와 남은 Anlas를 먼저 보여주고 확인을 받아요.

대본으로 컷 만들기를 누르면 오른쪽 원고에 컷이 깔려요. 전체 생성은 아직 그림이 없는 컷을 위에서부터 한 장씩 생성하고, 각 컷의 생성·새 버전 버튼으로 하나씩 다시 뽑을 수도 있어요. 대본을 고쳐서 다시 적용해도 내용이 바뀌지 않은 컷의 그림과 말풍선 위치는 그대로 남아요.

4. 말풍선 다듬기

  • 말풍선을 끌어서 옮기고(모바일은 한 번 탭해 선택한 뒤 끌기), 선택하면 나오는 오른쪽 아래 파란 점을 끌어 폭을 조절해요.
  • 두 번 클릭(모바일은 두 번 탭)하면 글자를 바로 고칠 수 있어요. 선택한 상태에서 Delete로 지워요.
  • 말풍선을 선택하면 컷 아래에 도구 막대가 나와요. 미리보기 그림을 눌러 말풍선·상자 종류를 바로 바꾸고, 꼬리 방향(자동·왼쪽·가운데·오른쪽·없음)과 화자를 고르고, 복제·삭제할 수 있어요.
  • 종류는 말풍선·각진 말풍선·속삭임·생각·외침·떨리는 말·전화·기계음·글자만, 상자는 나레이션·독백·자막·상태창, 그리고 효과음까지 13가지예요.
  • 도구 막대에서 풍선마다 글꼴(나눔고딕·나눔명조·고운돋움·도현·주아·검은고딕·손글씨 2종), 크기, 굵게, 기울임, 정렬(왼쪽·가운데·오른쪽), 줄간격, 자간, 글자색을 바꾸고, 효과음·글자만은 기울기도 조절해요.
  • 색상: 모양은 그대로 두고 칠만 바꿔요. 먹색·벚꽃·복숭아·레몬·민트·하늘·라일락·빛바랜 종이·밤하늘·핏빛·황금·반투명 12가지. 독백 상자는 반전색, 상태창은 그 색으로 빛나요.
  • 효과: 그림자 · 빛나는 후광 · 테두리 없이 부드럽게 · 굵은 테두리 · 이중 테두리 · 점선 · 그라데이션 · 흔들림 잔상 · 반짝이 · 찢긴 가장자리(나레이션·독백·편지). 효과음 글자에도 같은 효과가 들어가요.
  • 마음에 드는 서식은 이 서식을 모든 "말풍선"에 적용으로 같은 종류 풍선 전체에 한 번에 입히고, 서식 초기화로 되돌려요.
  • 각 컷 아래 대사 편집에서도 종류와 화자를 바꾸거나 새로 추가할 수 있어요.
  • 원고에서 고친 내용은 대본 탭의 원고 → 대본 반영으로 대본 글에 옮길 수 있어요. 그다음 대본을 다시 적용해도 그림과 말풍선 위치가 그대로 남아요.
  • 컷 메뉴(⋯)의 연출에서 검은·흰 화면 컷, 흑백·세피아·회상 필터, 컷 아래 간격을 바꿔요.

5. 저장

  • 긴 PNG 한 장: 원고 전체를 세로로 이어 붙인 이미지
  • 분할 PNG ZIP: 플랫폼 업로드용으로 정해진 높이씩 자른 이미지 묶음 (설정 탭에서 높이 지정)
  • 웹툰 뷰어(HTML): 브라우저에서 세로로 넘겨 보는 페이지 한 장. 깃허브에 올리면 링크로 공유할 수 있어요.
  • 프로젝트 파일(.json): 그림과 말풍선을 모두 담은 작업 파일. 다른 기기에서 이어서 작업할 때 불러와요. 불러오면 새 원고로 추가돼요.
  • 원고 목록: 화마다 원고를 따로 저장하고 오가요. 새 화 만들기는 등장인물·의상·설정을 이어받아 다음 화를 시작해요.

작업 내용은 이 브라우저에 자동 저장되지만, 브라우저 데이터를 지우면 사라져요. 중요한 원고는 프로젝트 파일로도 받아 두세요.
