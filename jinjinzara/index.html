STEP 1 · 토큰 발급 안내

NovelAI 영구 API 토큰 만들기

한 번만 하면 돼요. 3분 정도 걸립니다.

이미지 생성은 NovelAI 유료 구독(Tablet 이상)이 있어야 해요. Opus 구독이면 기본 크기 컷을 Anlas 없이 생성할 수 있어서 웹툰 작업에 가장 유리해요.

  1. NovelAI에 로그인

    novelai.net/image에 접속해 평소 쓰는 계정으로 로그인해요.

  2. Account Settings 열기

    이미지 생성 화면 오른쪽 위 ☰ 메뉴를 누르면 계정 메뉴가 열려요. 맨 위 Account 항목의 Account Settings를 눌러요.

    Anlas: 10004☰
    AuthorOpus Tier
    Account
    ⚙ Account Settings
    Logout
    Other
    Explore
    Director Tools

  3. Get Persistent API Token 누르기

    Account Settings 창 안에서 Get Persistent API Token 버튼을 찾아 눌러요.

    Account
    Change Email
    Get Persistent API Token

  4. Overwrite 확인

    "덮어쓰기(Overwrite)" 확인 창이 떠요. 처음 만드는 경우에도 이 문구가 나오니 그대로 Overwrite를 누르면 됩니다.

  5. 토큰 복사해서 보관

    복사 아이콘을 누르거나 Show Full Token으로 전체를 확인해 복사해요. 보통 pst-로 시작하는 긴 문자열이에요.

    pst-••••••••••••••••••••••••••••••••••••
    창을 닫으면 다시 볼 수 없어요. 메모장에 먼저 붙여두세요.

  6. 진진자라에 붙여넣기

    토큰 연결 화면에 붙여넣고 연결 확인을 누르면 끝이에요.

꼭 알아둘 점
· 토큰은 비밀번호와 같아요. 다른 사람에게 보내거나 공개된 곳에 붙여넣지 마세요.
· 새 토큰을 발급하면 예전 토큰은 바로 무효가 돼요. 유출이 의심되면 재발급하면 됩니다.
· 다른 프로그램(ComfyUI 플러그인 등)에도 같은 토큰을 쓰고 있었다면, 재발급 후 그쪽도 새 토큰으로 바꿔야 해요.

-남은 Anlas

토큰은 이 브라우저 저장소에만 보관되고, 생성 요청을 보낼 때 NovelAI 서버(novelai.net)로만 전송돼요. 진진자라는 따로 서버가 없어서 토큰이나 그림을 받아 가지 않습니다.

STEP 3 · 사용 방법

제작실 사용 방법

등장인물 등록 → 대본 → 컷 생성 → 말풍선 정리 → 저장 순서로 작업해요.

1. 등장인물 등록

제작실 등장인물 탭에서 인물을 추가하고 이름과 외형 태그(영어 Danbooru 태그)를 적어요. 이 태그가 그 인물이 나오는 모든 컷에 들어가서 외형이 유지돼요.

  • NovelAI로 뽑은 PNG를 올리면 그림 속에 저장된 프롬프트를 읽어 외형 태그를 자동으로 채워요.
  • 캐릭터 레퍼런스를 켜면 올린 이미지를 NovelAI V4.5의 캐릭터 레퍼런스로 함께 보내 얼굴과 옷을 더 비슷하게 맞춰요. 대신 컷마다 Anlas가 추가로 들어요(Opus도 무료 대상 아님).

2. 대본 쓰기

대본 탭에 아래 형식으로 써요. # 로 시작하는 줄이 새 컷이에요.

쓰는 법뜻
# 컷새 컷 시작 (---도 가능)
장면: 2boys, rooftop, night, rain, cowboy shot배경·구도·인원 태그 (영어)
비율: 가로컷 모양: 세로(기본) · 가로 · 정사각
서진(smile, looking at viewer): 늦었잖아.인물 등장 + 표정·행동 태그 + 말풍선
서진(back to viewer)대사 없이 등장만
서진 생각: 이번엔 안 놓쳐.생각 풍선 (구름 모양)
서진 외침: 기다려!외침 풍선 (뾰족한 모양)
서진 속삭임: 쉿.속삭임 풍선 (점선)
서진 떨림: 괜, 괜찮아…떨리는 말 (물결 테두리)
서진 전화: 여보세요?전화·기계음 (이중 테두리 네모)
서진 각진: 알겠어.각진 말풍선 (둥근 네모)
서진 글자: 하아…풍선 없이 글자만
나레이션: 그날 밤.흰 나레이션 상자
독백: 그때 알았어야 했다.검은 독백 상자
자막: 서울, 오후 6시장소·시간 자막
상태창: [퀘스트] 첫 만남게임 상태창 스타일 상자
효과음: 쾅그림 위에 얹는 큰 글자

인물 이름은 등장인물 탭에 등록한 이름과 정확히 같아야 그 인물의 외형 태그가 붙어요. 한 컷에 인물은 3명까지가 안정적이에요. 장면: 맨 앞에 1boy, 2boys, 1girl, 1boy 같은 인원 태그를 넣으면 인물 수가 정확해져요.

줄글 스토리만 있다면

AI 콘티 프롬프트 복사 버튼을 누르고 스토리를 붙여넣으면, 등장인물 목록과 형식 규칙이 들어간 요청문이 복사돼요. Claude나 ChatGPT에 그대로 붙여넣고, 돌아온 대본을 대본 탭에 붙여넣으면 됩니다.

3. 컷 만들기와 생성

대본으로 컷 만들기를 누르면 오른쪽 원고에 컷이 깔려요. 전체 생성은 아직 그림이 없는 컷을 위에서부터 한 장씩 생성하고, 각 컷의 생성·새 버전 버튼으로 하나씩 다시 뽑을 수도 있어요. 대본을 고쳐서 다시 적용해도 내용이 바뀌지 않은 컷의 그림과 말풍선 위치는 그대로 남아요.

설정Opus 구독그 외 구독
기본 크기(832×1216 등), 28스텝 이하0 Anlas컷당 약 17 Anlas
캐릭터 레퍼런스 사용컷당 약 5 Anlas 추가컷당 약 5 Anlas 추가

Anlas 수치는 생성 전에 진진자라가 계산한 추정치예요. 실제 차감은 NovelAI 기준이며, 생성 버튼 옆에 예상치가 표시돼요.

4. 말풍선 다듬기

  • 말풍선을 끌어서 옮기고(모바일은 한 번 탭해 선택한 뒤 끌기), 선택하면 나오는 오른쪽 아래 파란 점을 끌어 폭을 조절해요.
  • 두 번 클릭(모바일은 두 번 탭)하면 글자를 바로 고칠 수 있어요. 선택한 상태에서 Delete로 지워요.
  • 말풍선을 선택하면 컷 아래에 도구 막대가 나와요. 미리보기 그림을 눌러 말풍선·상자 종류를 바로 바꾸고, 꼬리 방향(자동·왼쪽·가운데·오른쪽·없음)과 화자를 고르고, 복제·삭제할 수 있어요.
  • 종류는 말풍선·각진 말풍선·속삭임·생각·외침·떨리는 말·전화·기계음·글자만, 상자는 나레이션·독백·자막·상태창, 그리고 효과음까지 13가지예요.
  • 각 컷 아래 대사 편집에서도 종류와 화자를 바꾸거나 새로 추가할 수 있어요.

5. 저장

  • 긴 PNG 한 장: 원고 전체를 세로로 이어 붙인 이미지
  • 분할 PNG ZIP: 플랫폼 업로드용으로 정해진 높이씩 자른 이미지 묶음 (설정 탭에서 높이 지정)
  • 프로젝트 파일(.json): 그림과 말풍선을 모두 담은 작업 파일. 다른 기기에서 이어서 작업할 때 불러와요.

작업 내용은 이 브라우저에 자동 저장되지만, 브라우저 데이터를 지우면 사라져요. 중요한 원고는 프로젝트 파일로도 받아 두세요.
